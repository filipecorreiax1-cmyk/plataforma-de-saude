# Plataforma de Saúde

## Sobre o projeto

Plataforma digital para facilitar o acesso
da população aos serviços de saúde.

## Objetivos

- Agendamento de consultas.
- Cancelamento de consultas.
- Consulta de vacinas disponíveis.
- Calendário municipal de vacinação.
- Gerenciamento administrativo.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- PostgreSQL
- Prisma ORM
- Git e GitHub

## Segurança

- Controle de acesso RBAC.
- Proteção de dados pessoais.
- Autenticação segura.
- Auditoria de operações.

## Status

Em desenvolvimento.
